ISP Management

A React-based dashboard for managing ISP subscribers and their internet services.

Features

- Dashboard with online, offline, paused and reported issue statistics.
- Search subscribers by name or IP address.
- View customer details.
- Upgrade internet speed.
- Pause and resume internet services.

Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

Getting Started

npm install
npm run dev

Currently uses mock data.
